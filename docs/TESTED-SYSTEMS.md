# Tested systems

The machines behind the ✅ rows of the [Tested / untested](../README.md#tested--untested)
tables in the README: every setup here has had a real backup and a
`backup-verify.sh` pass, and — where the last column says so — a bare-metal
restore onto a blank test drive with [`testbed/testbed.sh`](../README.md#the-restore-test-bed),
booted and compared against the archive (`VERDICT: PASS`).
